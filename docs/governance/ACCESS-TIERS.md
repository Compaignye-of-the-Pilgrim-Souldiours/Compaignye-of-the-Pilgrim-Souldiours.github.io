# Access tiers

Define who may see which digital assets. Implement these rules in Google Drive sharing, Sheet column protection, and Workspace admin roles — not in the public website.

Aligned with draft **By-law No. 3** (data governance) and **By-law No. 1** (marshalate). Adjust if inauguration adopts different wording.

## Tier A — Prior and Arca

Per draft By-law No. 3:

- Membership contact details held as sensitive
- Health / medical disclosures
- Insurance records and policy references
- Ability to export membership data for insurers or regulators when required

Both roles should hold access so absence of one person does not lock the association out.

## Tier B — Armorum / Marshalate

- Marshal’s Log and weapon/armour inspection ledgers (retain ≥ 7 years per By-law No. 3)
- Event Conclave / post-fight minutes
- Kit history and combat-safety operational files
- Incident templates used on the field (full medical narrative stays Tier A where required)

## Tier C — Committee (Prior, Armorum, Arca, and other elected officers)

- Membership Sheet columns that are not Tier A
- Operational Records folder (non–Tier A)
- Public Assets folder (logos, press photos)
- Website repository write access (or PR approval rights)
- Workspace user management as assigned (prefer Arca + Prior as Workspace admins)

## Tier D — All members in good standing

- Research Library / Historical Library (view; optionally comment)
- Private member hub (announcements and discussion)
- Public website and public social channels

## Tier E — Public

- This GitHub Pages site
- Public social media (education, events, recruitment)
- Published foundational PDFs marked as drafts until adopted

## Rules of thumb

1. **No Tier A data in git, Discord, or public social.**
2. **Personal Google accounts are not the system of record** for association files.
3. When someone leaves office, remove their elevated sharing the same week; do not wait for AGM paperwork alone (By-law No. 3 annual audit still applies).
4. Review sharing quarterly (Arca owns the calendar reminder).
