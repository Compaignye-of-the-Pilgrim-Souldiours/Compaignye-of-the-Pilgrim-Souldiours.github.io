# Drive structure

Create these folders at the root of a Shared Drive named e.g. **Pilgrim Souldiours — Association** (Shared Drives survive membership changes better than “My Drive”).

```
Pilgrim Souldiours — Association/
├── 01 Public Assets/
│   ├── Logos/
│   ├── Press and media photos/
│   └── Brand guidelines/
├── 02 Operational Records/
│   ├── Insurance certificates/
│   ├── Incident report templates/
│   ├── Kit history documentation/
│   ├── Marshals Log (Sheet + Form links)/
│   └── Event Conclave (Sheet + Form links)/
└── 03 Research Library/
    ├── Manuscript scans 1375-1425/
    ├── Pattern database/
    └── Bibliographies/
```

## Sharing

| Folder | Who | Access |
|---|---|---|
| 01 Public Assets | Committee | Edit |
| 01 Public Assets | Members (optional) | View |
| 02 Operational Records | Committee | Edit |
| 02 Operational Records / incidents (if split) | Host + Yeoman only | Edit |
| 03 Research Library | All members | View (Comment optional) |
| 03 Research Library | Committee / librarians | Edit |

Follow [../governance/ACCESS-TIERS.md](../governance/ACCESS-TIERS.md).

## Naming conventions

- Prefer ISO dates in filenames: `2026-07-26-weapon-inspection-sheet`
- Do not upload member health documents to Public Assets or Research Library
- Keep Form response Sheets inside the Operational Records subfolders above
